# COGVERITAS — довідник оператора (аналітика)

Робочий інструмент для розбору свідчень/допитів. **Не детектор брехні.** Він
розкладає показ на перевірювані факти, будує хронологію, ловить розбіжності й
каже, який зовнішній запис підняти. Рішення завжди за людиною — вирок про людину
система не виносить (структурно, `verdict = null`).

## Потік роботи

1. **Введення.** Встав текст показу або завантаж транскрипт (`SRT` / `VTT` /
   `CSV` / `JSON`). Формат `Свідок: репліка` дає крос-звірку між свідками.
2. **Розбір.** Система повертає:
   - **Сутності справи** — імена, згорнуті з відмінюваних форм, з лічильником;
   - **Профілі свідків** — скільки з кожного показу перевірюване;
   - **Крос-звірку** — суперечності й взаємні підтвердження між свідками;
   - **Хронологію** — впорядковані за часом твердження;
   - **Потенційні суперечності** — протилежні твердження / розбіжності в числах;
   - **Лист корроборації** — кожне твердження → тип запису (білінг, камери,
     банк, прикордон, реєстр);
   - **Голослівні твердження** — те, що нічим не перевірити.
3. **Відстеження.** Познач кожен пункт листа: `очікує` → `підтверджено` →
   `спростовано` (кнопка статусу). Прогрес рахується автоматично.
4. **Досьє.** «Завантажити досьє (.md)» — друкований звіт зі статусами,
   провенансом і **відбитком цілісності**.

## Цілісність (chain-of-custody)

Кожне досьє має відтворюваний `case_id` та SHA-256 джерела й аналізу. Той самий
текст завжди дає той самий хеш; будь-яка зміна змінює його. Перевірка:
`POST /api/v1/cogveritas/verify-integrity` з `{text, expected}` → `{match}`.

## Ендпоінти

| Метод | Шлях | Призначення |
|---|---|---|
| POST | `/api/v1/cogveritas/verifiability` | розбір тексту/транскрипту (`?format=markdown` → досьє) |
| POST | `/api/v1/cogveritas/case` | розбір зі статусами корроборації |
| POST | `/api/v1/cogveritas/verify-integrity` | звірка відбитка з джерелом |
| GET | `/api/v1/cogveritas/capabilities` | що вміє і чого НЕ робить |
| GET | `/api/v1/cogveritas/methodology` | наукова основа рішення «без вироку» |

## Межі (скажи це першим)

- Не визначає брехню й не дає ймовірності обману — пасивна текстова детекція
  брехні не працює на реальній high-stakes брехні (RLT AUC ≈ 0.56, CI перекриває
  випадковість; див. `docs/EMPIRICAL_VALIDATION.md`).
- Не вирішує, чи твердження істинне — лише чи воно зовнішньо перевірюване.
- Жодного аудіо/відео/фізіологічного висновку — тільки текст.
- Кожен висновок — вказівка для людини; висновок робить аналітик.
